# Clothes Have Pockets

A Vintage Story mod: wear trousers, a coat, an apron or a working belt and you get extra inventory slots - pockets. What has pockets, and how many, is one JSON attribute, so any clothing mod can be given pockets with a small patch.

- Mod page: https://mods.vintagestory.at/clotheshavepockets
- Guide for modders: [MODDERS.md](MODDERS.md)
